# AGENTS.md — Запись к мастеру

## О проекте
Инструмент для четырёх мастеров барбершопа и администратора, с телефона и компьютера. Мастера записывают клиентов с 10:00 до 22:00 на 30–90 минут: дата, время, мастер, пол, возраст, категория и сложность стрижки, необязательный комментарий.
Первый вариант работает в одном браузере: мастер и администратор видят одни данные localStorage. Синхронизации устройств и авторизации пока нет. index.html — макет формы без сохранения и расписания.
Файлы: index.html — разметка, styles.css — вид, script.js — логика.
Требования к функциям — в папке specs/. Описание для людей — в README.md.

## Правила
- Только HTML, CSS и JavaScript в этой папке. Без npm, библиотек и внешних ресурсов.
- Данные храни в браузере (localStorage). Ничего не отправляй в интернет.
- Интерфейс на русском языке, подписи короткие и понятные.
- Кнопки и поля не меньше 44px, страница работает на телефоне шириной 375px.
- Делай только то, о чём попросили. Работающие функции не ломай.
- Коммит и push — только после проверки пользователя и его «да», по разделу «Git».
- Четыре мастера с постоянными идентификаторами; до уточнения имён — «Мастер 1» — «Мастер 4».
- Время показывай как ЧЧ:ММ, даты — по местному времени устройства. Запись начинается не раньше 10:00 и заканчивается не позже 22:00.
- Предварительно начало с шагом 30 минут, длительность — 30, 60 или 90 минут. Категория и сложность не меняют длительность автоматически.
- Пересечения у одного мастера в один день запрещены; соседние интервалы и одновременные записи разных мастеров разрешены.
- Неверные обязательные поля не сохраняй, покажи подсказку. Никогда не показывай NaN, Infinity или неверную дату. Ошибку localStorage не выдавай за успех.
- Для записей используй отдельный ключ localStorage. Прежние данные расходов не удаляй и не преобразуй.

## Как проверить
- Открыть index.html двойным щелчком.
- В текущем макете проверить название, четыре варианта мастера и поля записи; кнопка сохранения отключена.
- После реализации: создать мастеру 1 запись 10:00 на 60 минут, проверить окончание 11:00.
- Попробовать 10:30 ему же — отказ; 11:00 ему же и 10:30 мастеру 2 — разрешены.
- 20:30 на 90 минут разрешено, 21:00 на 90 минут отклоняется.
- После F5 записи на месте, у администратора видны те же записи всех четырёх мастеров за выбранный день.
- Проверить доступность страницы при ширине 375 px без горизонтальной прокрутки.

## Git
- Коммит и push делаешь ты, но только после моей проверки и моего «да».
- Перед работой выполни git status. Есть незакоммиченные изменения — скажи и спроси, что с ними делать.
- Сделал шаг или файл требований и проверил сам — остановись. Покажи изменённые файлы (git status --short), напиши, что мне проверить руками, и спроси: «Коммитим?»
- «да» значит только коммит, а не следующий шаг. На «да» выполни по очереди: 1) git add . 2) git commit -m "<короткая подпись по-русски>" 3) git push.
- git remote -v пустой — push пропусти и скажи об этом. Push просит upstream — выполни git push -u origin <текущая ветка>. Push отклонён или просит вход — остановись и покажи ошибку целиком.
- Любая команда git не выполнилась — остановись, покажи ошибку целиком и ничего не обходи.
- Я ответил «нет» или описал ошибку — исправь, проверь снова и снова спроси. Без моего «да» не коммить.
- Историю не переписывай: без git reset --hard и git push --force.
