# Обзор записей для администратора

## Для кого и зачем
Для администратора барбершопа: видеть записи и загрузку всех четырёх мастеров на выбранный день. Использует общие данные из спецификаций 001 и 002.

## Что должно быть
- Переключатель «Мастер» / «Администратор»: представления в одном браузере, без паролей и разграничения прав.
- Выбор даты, по умолчанию сегодня, и расписания всех четырёх мастеров на 10:00–22:00.
- У каждого мастера — записи по времени, свободные промежутки и число записей за выбранный день. Для пустого дня — «Записей нет» и свободно 10:00–22:00.
- Карточки показывают начало, окончание, длительность, пол, возраст, категорию, сложность и комментарий, если заполнен.
- Общий счётчик дня равен сумме записей четырёх мастеров. Другие даты не учитываются.
- Переключение представлений не копирует данные. Новая запись сразу видна в обзоре; изменения из другой вкладки того же браузера обновляют обзор.
- На телефоне расписания идут последовательно с именами мастеров, без горизонтальной прокрутки.

## Примеры
- У мастера 1 две записи, у мастера 2 одна, у остальных ноль → общий счётчик 3, видны все четыре мастера.
- Два мастера заняты в 10:00 → обе записи видны отдельно, конфликта нет.
- Выбрать пустую дату → счётчик 0, каждый мастер свободен 10:00–22:00.
- Создать запись в режиме мастера и перейти к администратору → видна та же запись со всеми полями.

## Ограничения
- Пользователь подтвердил первый вариант в одном браузере. Синхронизации устройств нет; ограничения нескольких вкладок описаны в 002.
- Переключатель не защищает данные от просмотра. Учётные записи, доступ по ролям и серверная база требуют отдельного согласования.
- Оплата, доходы, зарплаты, экспорт, уведомления и аналитика за месяц пока не входят в функцию.
- Только HTML, CSS, JavaScript и localStorage без внешних ресурсов. Данные расходов не используются и не удаляются.
- До команды «делай» логика не реализуется. Новые файлы тестов не создаются, README.md обновляется после последнего шага.

## Готово, когда
- Видны все четыре мастера, включая мастеров без записей, за выбранную дату.
- Карточки совпадают с расписанием мастера, порядок хронологический, свободные промежутки верны.
- Счётчики соответствуют примерам и обновляются при смене даты и добавлении записи.
- Переключение представлений не теряет и не дублирует записи; после F5 данные доступны в обоих представлениях.
- Изменения из другой вкладки обновляют обзор; на компьютере и ширине 375 px данные читаемы, пустой день понятен.
- README.md описывает обзор и ограничение одного браузера.

## Шаги
- [ ] 1. Обзор дня. После реализации 001 и 002 появляются переключатель, дата и четыре расписания. Проверка: (1) добавить запись мастеру 1 и перейти к администратору; (2) сверить поля и наличие остальных мастеров; (3) выбрать пустой день.
- [ ] 2. Счётчики и актуальность. Появляются количества по мастерам и общий счётчик, обновление между представлениями и вкладками. Проверка: (1) создать две записи мастеру 1 и одну мастеру 2, проверить итог 3; (2) добавить запись в другой вкладке, проверить обновление; (3) сменить дату, проверить счётчики этого дня.
- [ ] 3. Проверка и завершение. Обзор доступен на телефоне, данные восстанавливаются, обновлён README.md. Проверка: (1) нажать F5 и сверить карточки и счётчики; (2) переключить представления, проверить отсутствие дублей; (3) прочитать расписания на ширине 375 px без горизонтальной прокрутки.
